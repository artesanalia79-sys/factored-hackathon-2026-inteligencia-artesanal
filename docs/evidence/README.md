# Problem evidence

Generated by `uv run poe analysis` (Task 16, Juan José). Contains only **aggregates** computed from
the organizer data (counts, rates, distributions), never row-level data or personal information.

Planned contents:

- `call_center_baseline.md`: dispute-related contact volume, handling time, first-contact
  resolution and cost per contact by country and channel.
- `complaints_baseline.md`: dispute volume, resolution days and outcomes.
- `roi.md`: cost per resolution for the current process vs. the agent, with a tornado
  sensitivity chart over the uncertain assumptions.

Every number states the query or dbt model that produced it and the data snapshot (manifest hash).
