# Call-center baseline (offline measurement)

Generated by `uv run poe analysis` (Task 16). Aggregates only: counts, rates and quantiles, never row-level data. Every table names the query that produced it (`data_pipeline/dbt/analyses/`), run on the warehouse of this snapshot:

- bronze manifest sha256 `8044bf9b34c6e38d872fa17928a7cedd2e5a513d64fd3b6d712117f21284d50d`
- silver built at 2026-10-01T21:55:13+00:00 (`data_mode=curated`)
- span: 1,097 days of process dates

Label: every number here is **measured** from the organizer data (offline). Nothing is projected. The ROI model that uses these numbers is in `roi.md`.

## Key facts

- 686,296 contacts, about 228,348 per year.
- The source has no dispute label: `contact_reason` has 6 values. `Transaccional` (35.0% of contacts) is the closest one and only an upper bound for dispute contacts; its phone contacts last 3.68 min on average (the talk time the ROI model uses for a dispute received by phone).
- First-contact resolution differs by **reason** (spread 47.9 percentage points) but hardly by channel (0.6), segment (0.2) or country (0.1); durations behave the same way (tables below).
- `was_resolved` (first-contact resolution) does not predict repeat contacts: resolved and unresolved contacts repeat at the same rate within 7 days.
- Agents declare 451,168 interactions per month; the interactions table holds 19,029 per month (x23.7). The interactions table may be a sample, but nothing shows that complaints are sampled the same way, so `roi.md` does not scale disputes by this factor.
- The placebo test finds no detectable link between complaints and contacts, not even by customer and date (`complaints_baseline.md`), so contacts per dispute is not measurable.
